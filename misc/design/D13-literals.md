# D13 Literals

| Item | Options | Recommendation |
|---|---|---|
| Integers | dec / `0x` / `0o` / `0b`, `_` separators, suffix `i8..u64` | keep luv60's set. Accumulate inline. Check overflow per suffix in the lexer |
| Floats | `1.0`, `1e9`, `1.5e3`; C-style `1.f`? | a float needs a digit after `.` or an exponent. `1.` and `.5` are errors. Suffixes mirror ints: `1.0f32`, `1f32`, `2.5f64` (optional alias `f` = `f32`), decimal only (`0x1f` is hex 31). **No C-style `1.f` / `1.e5`**: with methods on scalars (`on int def f`), `1.f` is ambiguous with a method call, so `1.foo()` stays int + method. The `a.b` vs `1.0` trouble in luv60 (`lex.c:384`) comes from its parallel indexer. A sequential number reader owns the `.` after a digit, with byte lookahead made safe by padding. Lexer calls strtod only for floats |
| Strings | `"..."` only, or `'...'` too | `"` only. Then `'` stays free (for codepoint literals, maybe) |
| Escapes | `\n \t \\ \" \0 \xHH \u{...}` | scan to the closing quote. If no `\` was seen, the string token is a **slice of the source** (zero copy). Otherwise decode into the arena (Lua 4 always copies through `Mbuffer`) |
| Raw / multiline strings | Lua `[[...]]` | **not `[[`**: it collides with nested arrays/lists. If needed, use `r"..."` and `"""..."""` |
| Interpolation | `fmt("...{}", a)` call vs. `f"...{a}"` vs. Swift `"...\(a)"` | **Decided: Swift `\(expr)`; `fmt(...)` dropped.** luv60's trouble was its SIMD quote-pairing indexer, which treats string contents as opaque. A sequential lexer uses a mode stack, as Swift, Kotlin and JS templates do: the string reader returns `STRING_BEGIN` at `\(` and pushes the bracket depth onto `interp_stack`. Normal tokens follow (nested strings are fine). The `)` that returns to that depth pops it and resumes the string, returning `STRING_MID`/`STRING_END`. A string with no `\(` is still one zero-copy `TK_STRING`. Grammar: `STRING \| STRING_BEGIN expr {STRING_MID expr} STRING_END`, LL(1), and the token kind says up front whether a string is interpolated. Cost: one compare per `)` while the stack is non-empty. Rules: a raw newline inside a string, including inside `\( )`, is an error, so strings stay atomic for the formatter. A literal `\(` is written `\\(`. Deferred: format specs (a lexer-only `\(x:08x)` is possible because nothing else uses a depth-0 `:` there). Continued in [D35](D35-interpolation-formatting.md). Test impact: 17 tests use `fmt(` and get rewritten. The `errors/fmt_*` tests (6) go away. Cost elsewhere: editor highlighting needs nested regions |
